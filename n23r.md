# Problem 23: odd length or s = `01`

**Language:** {s | s has odd length, or s = 01}, over Σ = {0, 1}

## NFA and batch run

![NFA and batch run for #23](n23_batch.png)

## Design

| State | Meaning | on 0 | on 1 |
|---|---|---|---|
| A (start) | nothing read yet | {B, D} | {B} |
| B (accepting) | odd number of symbols read | {C} | {C} |
| C | even number of symbols read | {B} | {B} |
| D | read a `0` as the first symbol | none | {E} |
| E (accepting) | read exactly `01` | none | none |

A has no incoming edges, so the `01` branch can only be taken at the very start of the string.

## Test strings (`n23t.txt`)

| String | Expected | JFLAP result |
|---|---|---|
| `0`, `1`, `01`, `000`, `101`, `01010`, `11111` | accept | accept |
| `00`, `10`, `11`, `0101`, `0110`, `1111` | reject | reject |

`01` is the only accepted string of even length. `0101` is the corner case: the first two symbols follow the `01` branch, but the string keeps going and that thread dies.
