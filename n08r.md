# Problem 8: starts with `01` and ends with `10`

**Language:** {s | s starts with 01 and ends with 10}, over Σ = {0, 1}

## NFA and batch run

![NFA and batch run for #8](n08_batch.png)

## Design

| State | Meaning | on 0 | on 1 |
|---|---|---|---|
| A (start) | nothing read | {B} | none |
| B | read the `0` of the prefix | none | {C, D} |
| C | prefix `01` done, absorbing the middle | {C} | {C, D} |
| D | guessed that this 1 starts the final `10` | {E} | none |
| E (accepting) | read the final `10` | none | none |

The edge from B to D on 1 is the overlap edge. It lets one 1 serve as both the end of the prefix `01` and the start of the suffix `10`. That is what makes `010` accepted.
