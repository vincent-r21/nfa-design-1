# Problem 9: strings that contain the substring `10`

**Language:** {s | s contains the substring 10}, over Σ = {0, 1}

## NFA and batch run

![NFA and batch run for #9](n09_batch.png)

## Design

| State | Meaning | on 0 | on 1 |
|---|---|---|---|
| A (start) | still looking for a `10` | {A} | {A, B} |
| B | guessed that the 1 just read starts a `10` | {C} | none |
| C (accepting) | a `10` has been seen | {C} | {C} |

This is the same shape as #7, except that C loops on 0 and 1. Once a `10` has appeared, the rest of the string doesn't matter, so the thread in C survives to the end of the input.

## Test strings (`n09t.txt`)

| String | Expected | JFLAP result |
|---|---|---|
| `10`, `010`, `110`, `0101`, `1100`, `0110` | accept | accept |
| `0`, `1`, `01`, `00`, `11`, `0011`, `000111` | reject | reject |

`0011` and `000111` have both symbols but never a 1 followed by a 0.
